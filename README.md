# neterm

跨平台终端工作空间：Local、SSH、tmux、RDP、VNC、文件管理与 Cloud Storage，都在同一个窗口里。

**[产品主页](https://rootec.pages.dev/neterm/)** · **[下载安装包](https://github.com/rootecme/neterm/releases)**

Linux x86-64 · Windows x86-64 · macOS Apple Silicon

[![neterm 界面](https://rootec.pages.dev/neterm/assets/hero.webp)](https://rootec.pages.dev/neterm/)

## 主要功能

- **Workspace** — 标签、自由分割和拖动布局，终端与远程桌面可以混合排布。
- **SSH 与 tmux** — 保存连接配置、断线重连，并通过 tmux 恢复长时间运行的 Shell 和 TUI。
- **RDP 与 VNC** — 远程画面自动缩放，可与本地终端并排使用。
- **Files** — 单栏 Explorer、双栏传输队列、上传下载、文件编辑和 Diff。
- **Cloud Storage** — 在同一文件工作流中浏览和传输 S3 兼容对象存储。
- **工具面板** — Snippets、端口转发、剪贴板、文件共享和局域网发现按需停靠。
